# Legacy: original FEBE sources

Theo Dodd's four original modules (`architecture.py`, `environment.py`,
`organism.py`, `population.py`) as delivered with the BSc(Hons) thesis
"One Continuum or Two Strategies?" (University of Otago, October 2026).
Kept verbatim for provenance and for the regression test in
`tests/test_legacy_equivalence.py`, which checks that `brainevo.abm`
reproduces the original model exactly for a shared random seed.

Do not import from here in new code.
